## 2. 单元测试用例

### 2.1 AI 解析

| 输入 | 预期输出 |
|------|---------|
| "午饭32" | `[{type:"expense", amount:3200, category:"餐饮"}]` |
| "早餐8，午饭25，地铁4" | 3 条记录，金额 800/2500/400 |
| "发工资12000" | `[{type:"income", amount:1200000, category:"工资"}]` |
| "微信转支付宝500" | `[{type:"transfer", amount:50000, account:"微信", target_account:"支付宝"}]` |
| "打车15.5" | amount = 1550 |
| "买了点东西" | 解析失败 |
| "昨天午饭30" | date = 昨天 |
| "微信付了咖啡28" | account = "微信" |
| "花了三十二块" | amount = 3200 |
| "" | 解析失败 |

### 2.2 分类匹配器

| AI 返回 | 预期匹配 |
|---------|---------|
| "餐饮" | 精确 → 餐饮 |
| "餐饮美食" | 包含 → 餐饮 |
| "饭" | 同义词 → 餐饮 |
| "吃饭" | 同义词 → 餐饮 |
| "出行" | 同义词 → 交通 |
| "买东西" | 同义词 → 购物 |
| "量子计算" | → 其他 |
| "" | → 其他 |

### 2.3 金额转换（元 → 分）

| 输入 | 输出 |
|------|------|
| 32 | 3200 |
| 15.5 | 1550 |
| 99.99 | 9999 |
| 0.01 | 1 |
| 0.1 + 0.2 | 30（Math.round） |
| 10000 | 1000000 |

### 2.4 幂等逻辑

| 操作 | 预期 |
|------|------|
| POST client_id=xxx | 创建 |
| 重复 POST 相同 client_id | 返回已有，不入库 |
| 不同用户同 client_id | 各自独立 |
| client_id 为空 | 正常创建 |

### 2.5 认证

| 操作 | 预期 |
|------|------|

| 过期邀请码 | 400 |

| 重复用户名 | 400 |

| 错误密码 | 401 |
| 禁用用户 | 401 |
| 无 token | 401 |
| 过期 token | 401 |
| 伪造 token | 401 |
| user 调 admin | 403 |

## 4. E2E 场景

| 场景 | 步骤 | 验证 |
|------|------|------|
| 注册完整流程 | 邀请码 + 用户名 + 密码 → 提交 | 进入引导 |
| 引导→记账 | AI 输入 "午饭32" → 确认 | 流水出现 |
| AI 批量记账 | "早餐8，午饭25，地铁4" → 3 张卡 → 全部确认 | 3 笔入库 |
| 确认卡片编辑 | 修改金额 → 确认 | 以修改后入库 |
| 确认卡片删除单条 | 3 条删 1 → 确认 | 2 笔入库 |
| AI 失败降级 | mock 超时 | 弹手动表单 |
| 手动记账 | 表单提交 | 入库显示 |
| 编辑交易 | 点流水 → 改金额 | 更新 |
| 删除交易 | 确认 | 流水消失 |
| 跨用户隔离 | user1 记账 → user2 登录 | user2 看不到 |
| 响应式-手机 | 375px | 底部 Tab |
| 响应式-PC | 1200px | 侧边栏 |
| 离线态 | 断网打开 | 显示手动表单 |

## 5. 安全测试

| 用例 | 验证 |
|------|------|
| SQL 注入 | 注入字符不影响系统 |
| JWT 伪造 | 401 |
| JWT 过期 | 401 |
| JWT 撤销（改密） | 旧 token 失效 |
| 越权-角色 | user 调 admin → 403 |
| 越权-数据 | 访问他人 ID → 404 |
| AI Key 泄露 | 前端代码不含 |
| XSS | `<script>` 转义 |
| CORS | 非白名单 Origin 被拒 |
| 限流 | 6 次登录 → 429 |
| Prompt injection | `<user_input>` 包裹后 LLM 不被劫持 |

## 7. 测试数据

### 7.1 固定数据
- 3 个邀请码（max_uses=1/5/不限）
- 1 个过期邀请码
- 1 个用完邀请码
- 2 个测试用户（验证隔离）
- 1 个 admin

### 7.2 交易测试数据
50+ 条覆盖：
- 支出/收入/转账
- 多分类多账户
- 跨月数据（验证月度边界）
- 含 pending / deleted 状态

### 7.3 Mock 数据
- LLM 正常 JSON / 超时 / 非法 JSON / 分类不匹配 / 无金额

## 8. 运行命令

```bash
# 单元 + 集成（Vitest）
cd server && npm test

# 单个文件
cd server && npx vitest run tests/routes/transactions.test.ts

# 监听模式
cd server && npx vitest --watch

# E2E（手动验证 Web）
cd web && npm run dev
```
