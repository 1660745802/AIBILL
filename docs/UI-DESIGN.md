# 前端 UI 设计规格 · 账本纸（Ledger Paper）

> 本文件是 `web/` 前端的视觉与交互契约。实现必须与本文一致；新增界面先在本文补设计，再写代码。

---

## 0. 现状诊断（为什么重做）

原前端存在**两套并行的设计语言**，同一产品里像两个 App：

| 分组 | 文件 | 问题 |
|------|------|------|
| 已改 | `Dashboard` `Assets` `Goals` `Home` | 暖米底 `#f8f7f4` + 靛蓝 `#4f46e5`，圆角卡片 + 柔和阴影 |
| 未改 | `Ledger` `Budget` `Login` `Register` `Import` `Subscriptions` `Settings` `Admin` `Onboarding` `ConfirmCards` `ManualForm` `EditTransactionModal` `TagInput` `EmptyState` `Skeleton` | Tailwind 默认 `gray-50`/`blue-600`/`green-600` 硬编码，`bg-white` 满幅色块 |

量化：13 个文件、约 350 处硬编码调色板 class；`index.html` 的 `theme-color` 还是旧的 `#2563eb`；无任何原子组件，页头/月份切换/分段 Tab/进度条/弹层/表单控件在 16 个页面里各写一遍且互不一致。

同时旧主题本身就是「暖奶油底 + 靛蓝圆角卡片」——即生成式 UI 最典型的两种外观。本次重做的目标不是修 bug，是**换一套有明确主张的视觉语言**。

## 1. 设计主张

> **这是一本账，不是 App。**

财务记账的本质是**一张纸**：横格、竖线、栏头、金额对位、双线压边。所有视觉决策从这条主张推导。

### 1.1 三条硬规则

1. **结构靠线，不靠卡片。** 内容分区由发丝线（`--color-rule`）和表格行（`.sheet-row`）承担。圆角盒子只出现在三处：真正的浮层（弹窗/抽屉）、需要物理边界的东西（上传区）、需要强调的主块。禁止"所有内容都放进圆角阴影卡片"。
2. **颜色只表达含义。** 红=支出，绿=收入，琥珀=提醒/警示，蓝=信息/中性操作。**主操作按钮是墨黑色，不是品牌色**——满屏彩色按钮是 SaaS 模板的默认长相，本产品不参与。品牌色留白，界面因此更像纸。
3. **金额必须对齐。** 全站 `tabular-nums`；大额数字整数部分重、小数部分轻（`.money-frac` 用 `0.62em` + 透明度降级），千分位分隔。眼睛必须能竖着扫一列数字。

### 1.2 色彩

```
墨 ink      #14171a  标题与主操作      ink-2 #4a5157  正文      ink-3 #7b838b  次要      ink-4 #a6adb4  占位
纸 paper    #eff1f3  页面             raised #ffffff 浮层/表格底  sunk #e6e9ec  输入框/槽  hover #e9ecef
线 rule     #dce0e4  主分隔            strong  #c1c7cd  输入框边框  faint   #eaecee 行间
支出        #c0392f / 底 #fbeceb / 线 #f0c9c5
收入        #1f7a54 / 底 #e7f3ed / 线 #b9dccb
警示        #a86312 / 底 #fbf2e1 / 线 #ebd6ab
信息        #2a5d8c / 底 #e9f0f6 / 线 #c3d7e7
```

**深色模式**：`prefers-color-scheme: dark` 下纸变 `#15171a`，语义色提亮到 `#ff7d70` / `#4fd3a0` / `#efb257` / `#79b3ea`，底色改为 12–14% 明度的深染。全部通过 `:root` 覆写实现，**任何组件不得硬编码色值**。

### 1.3 字体

单一字族（系统栈，中文落到 PingFang SC / Noto Sans SC），靠**字重 + 字距 + 尺寸**分层，不用第二套字体：

| 角色 | 规格 |
|------|------|
| 主数字 | `2.25rem / 600 / -0.045em / tabular-nums` |
| 栏头 label | `0.6875rem / 600 / +0.06em`，后接一条延伸到底的发丝线 |
| 页标题 | `1.0625rem / 650` |
| 正文 | `0.875rem / 400 / 1.5` |
| 元信息 | `0.75rem / ink-3` |
| 代码/日志 | 等宽，仅用于 JSON 与日志 |

行宽上限 ~72 字符。

### 1.4 圆角与阴影

圆角只用 3/5/8/12px（账本纸不圆）。**阴影只给浮层**：`0 1px 2px /6%, 0 16px 40px -16px /22%`。页面内模块零阴影。

## 2. 布局

### 2.1 外壳

```
桌面 ≥1024                        平板 768–1023                手机 <768
┌─ 232 轨 ─┬─ 内容 1120 ────┐   ┌─ 68 图标轨 ─┬─ 内容 ─┐    ┌─ 吸顶条 ─────┐
│ 品牌     │                  │   │  ✎          │        │    │ 品牌   月份 👤│
│ ═══════  │                  │   │  ▦          │        │    ══════════════│
│ 每天     │                  │   │  ◔          │        │    ┌─────────────┐│
│  记一笔  │                  │   │  ⋯          │        │    │  内容        ││
│  账本    │                  │   └─────────────┴────────┘    │             ││
│  本月    │                  │                               │ 底部 5 槽 + FAB │
│  AI 助手 │                  │                               └─────────────┘│
│ ─────    │                  │                                                 │
│ 偶尔     │                  │                                                 │
│  资产…   │                  │                                                 │
│  设置    │                  │                                                 │
│ ─────    │                  │                                                 │
│ 用户 退出│                  │                                                 │
└──────────┴──────────────────┘
```

导航分组按**真实使用频率**而非功能类型划分：3 个月数据里 `budgets` / `financial_goals` /
`subscriptions` / `ai_memories` / `asset_snapshots` 五张表均为 0 行，而 500 笔交易来自
通知快捷记账。因此一级只留每天真正常用的四项，其余全部下沉。

- **桌面侧栏**：品牌区下压一条**会计双线**（`border-bottom: 3px double`）。导航分组之间用发丝线而非间距分隔。选中态 = 左侧 2px 墨条 + 墨色文字 + 纸 hover 底，**不用填充药丸**。底部固定用户块（首字母头像 + 昵称 + 角色徽标）。
- **平板**：侧栏收成 68px 图标轨，悬停出 tooltip。
- **手机顶部条**：品牌 + 当前周期 + 头像，`position: sticky`，双线压边。
- **手机底部导航**：5 槽，**中间 记账 为凸起 FAB**（墨色圆形，跨出导航条 12px）——记账是这个产品唯一的高频动作，必须一键可达。
- 内容最大宽 1120px 居中；`Dashboard` 在 ≥1024 时切换为 `1fr 340px` 双栏（主区 + 右侧栏，右侧栏 sticky）。

### 2.2 栅格与间距

4px 基准。页面区块间距 `24px`，卡片内 `16px`，行内 `12px`，紧凑行 `8px`。

### 2.3 断点

`sm 640 / md 768 / lg 1024 / xl 1280`。仅用 `md` 与 `lg` 两个断点控制布局，避免碎裂。

## 3. 组件清单（全部为新建原子组件）

| 组件 | 职责 | 变体 |
|------|------|------|
| `AppIcon` | 24×24 stroke 图标，统一 `1.75` 描边 | 16/20/24 |
| `Money` | 金额渲染：千分位 + 轻小数 + 符号 | size `sm/md/lg/hero`，tone `expense/income/neutral/muted`，sign `auto/plus/minus/none` |
| `PageHeader` | 吸顶页头（标题/副标题/操作槽/周期槽） | sticky / 静态 |
| `LedgerLabel` | 栏头：文字 + 延伸发丝线 | 实心（无线） |
| `StatTile` | 指标格：label / value / delta / hint | 横向 / 纵向；tone 继承 Money |
| `Meter` | 计量条 | tone `ink/warn/danger/income`；`percent` 超 100 截断并加条纹 |
| `SegmentedControl` | 分段控件 | 尺寸 `sm/md`，可横向滚动 |
| `PeriodNav` | `‹ 2026年9月 ›` | 可传 `disableFuture` |
| `BaseModal` | 浮层：手机底部抽屉 / 桌面居中 | `size: sm/md/lg`，`stickyFooter` |
| `EmptyState` | 空态：图标 / 标题 / 说明 / CTA | 图标可换 SVG |
| `Skeleton` | 骨架：行 / 卡片 / 图表 | `rows / lines / block` |
| `Notice` | 提示条 | `warn/danger/info/success/neutral`，可关闭 |
| `ToastHost` | 全局 Toast | 桌面顶部居中 / 手机底部（避开导航条） |
| `ConfirmHost` | 全局确认框 | 替换原生 `confirm()` |
| `SheetRow` | 表格行 | `clickable / active` |

### 3.1 移动端弹层规范

底部抽屉：顶部有 32×4 的拖拽条 → 圆角 12px 12px 0 0 → 吸顶标题栏（双线压边）→ 可滚动内容 → 吸底操作栏（双线压边 + `safe-bottom`）。桌面：居中，最大高度 85vh。

### 3.2 反馈

- **Toast**：桌面顶部居中、手机底部（`bottom: calc(导航高 + 安全区 + 12px)`）。左侧 3px 色条区分类型，4s 自动消失，点击即消。
- **破坏性确认**：统一 `ConfirmHost`，文案说明后果（"永久删除后无法恢复"），取消在左、确认在右；危险级确认按钮用描边红而非实心红（避免误触）。
- **加载**：骨架屏 > 转圈 > 文字"加载中"。超过 400ms 才显示骨架。
- **空态**：永远给出下一步动作，不写"暂无数据"了事。

## 4. 逐页设计

### 4.1 本月 `/overview`

**布局**：≥lg 双栏（主 `1fr` + 侧 `340px` sticky），以下单栏。

**主栏**
1. **净资产块**：不是渐变卡。栏头 `净资产` → 主数字 `hero` → 发丝线 → 三格微指标（本月支出 / 本月收入 / 储蓄率）带环比箭头。背景用 `.paper-ruled`（32px 横格）呼应"账本纸"。净资产为负时主数字转 `--color-expense`。
2. **待办提醒**（有才显示）：`Notice` 列表，超支=红、订阅到期=蓝、预算告警=琥珀，每条可单独关闭。
3. **本月预算**：每行 `图标 分类名 …… 百分比`，下方计量条；右侧 `已花/总额`。前 5 条，多余折叠为"查看全部"。
4. **近 7 日支出**：折线图，1px 墨线 + 极浅填充，无网格线，x 轴标签 `09-12`。全 0 时显示纸纹空态。
5. **最近交易**：`SheetRow` 列表，右对齐金额，点击进编辑抽屉。

**侧栏**
1. **资产配置**：一条横向堆叠条 + 图例行（色块 / 名称 / 金额 / 占比）。
2. **财务目标**：Top 3，进度条 + 预计完成日。
3. **订阅概览**：月均总额 + 活跃数 + 年化。
4. **快捷入口** → 收敛为 3 个 `SheetRow`，不再用三张图标卡。

**场景**

| 场景 | 设计 |
|------|------|
| 首次使用（全空） | 主栏净资产块下方插入引导块：一句说明 + 「记第一笔」墨色按钮 + 「导入账单」描边按钮 |
| 部分无数据 | 各分区独立 `EmptyState`，不隐藏整块 |
| 预算超支 | 计量条转红并显示 `120%`，行左侧加 2px 红条 |
| 无资产账户 | 资产配置显示纸纹空态 + 「添加账户」 |
| 加载中 | 净资产块用 3 行骨架，四宫格用 4 个 `Skeleton block`，图表用 160px 骨架条 |

### 4.2 记账 `/`（默认落地页）

**这是唯一允许"用力"的地方**——产品的核心动作是把一句话拆成多笔账。

```
┌ paper-ruled ────────────────────────────────┐
│ 栏头  记一笔 · 说一句话                       │
│ ┌────────────────────────────────────────┐ │
│ │ 午饭 32，打车 15                        │ │  ← 自增高 textarea，3 行起
│ └────────────────────────────────────────┘ │
│ [解析 ⏎]  [手动]              12 字         │
│ 午饭 早饭 咖啡 打车 地铁 买菜                 │  ← 快捷短语 chip，点击追加
└────────────────────────────────────────────┘
```

- 文本域最小 3 行、最大 8 行自适应；`Enter` 提交、`Shift+Enter` 换行。
- 主按钮墨色，宽度自适应；解析中按钮内联转圈并改文案「AI 正在拆解…」，文本域保持可编辑。
- 快捷短语 chip 横向可滚动，追加时用中文逗号 `，`，不产生 `,,`。
- **下方**：`今日流水` `SheetRow` 列表 + 当日小计。
- **解析结果**：`ConfirmCards` 从下淡入上移（`rise`），每条可编辑/删除；底部吸底「确认 3 笔」墨色按钮 + 「取消」。删除到最后一条时自动收起并把焦点还给输入框。
- **AI 失败**：输入框下方 `Notice danger`「AI 没听懂这句，已切到手动」并自动展开手动表单，不弹 Toast 打断。
- **预算超支**：确认成功后 `Notice warn` 内联在顶部，不只靠 Toast。

### 4.3 账本 `/ledger`

- 页头：标题 + `PeriodNav` + 右侧当月净额。
- `SegmentedControl`：流水 / 统计。
- 流水：搜索框（可清空）+ 类型分段（全部/支出/收入）。搜索框 `Esc` 清空，`Enter` 触发。
- 分组：组头行显示 `9月12日 周五`（左）与当日支出合计（右），吸顶在分组内滚动时保持可见（`sticky top-0`）。
- 行：`28px 圆角方块图标` + 描述 + 元信息（分类 · 账户 · 标签） + 右对齐金额。
  - 描述超长单行省略；元信息最多两段，第三段用 `+N` 收敛。
  - 转账用 `--color-info` 并在描述后加 `→ 目标账户`。
- 加载更多：按钮改为"已显示全部 N 笔"文字；滚动到底自动触发下一页（`IntersectionObserver`），带 3px 进度条反馈。
- 统计：月度三指标（带环比）→ 支出/收入切换 → 趋势折线 → 分类环形 + 图例 → 排行（名次用等宽数字右对齐）→ AI 总结（唯一允许渐变的位置，改为墨色描边卡 + 左侧 3px 墨条）。

### 4.4 资产 `/assets`

- 页头 + 「记录快照」描边按钮。
- 净资产主块（同总览语言）+ 资产/负债两格。
- 分布环形（底部图例）+ 净资产趋势折线（点数不足 2 时给引导）。
- 账户按类型分组，每组一个 `Sheet`，组头为浅底 + 类型名 + 小计。
- 行内展开编辑（不是弹窗）：展开区纸下沉底 + 两列字段 + 右下保存。

### 4.5 设置 `/settings`

- 用户块（头像 / 昵称 / `@用户名` / 角色徽标）+ 「退出登录」。
- 两个折叠区：修改密码、数据管理。折叠区标题行整行可点，右侧 chevron 旋转。
- 数据管理：四行操作（导出 JSON / 导出 CSV / 导入账单 / 回收站），每行带说明文字而非纯图标。
- 分类管理 / 账户管理各为一个 `Sheet`，内部行分隔用发丝线。

### 4.6 导入 `/import`

四步，每步顶部一条**步骤条**（4 段横线，已完成段为墨色，当前段下方加 2px 墨点）：

1. **选来源**：微信 / 支付宝 两个大选项（选中 = 墨色边框 + 勾）。
2. **上传**：虚线拖放区（`paper-ruled` 底），显示文件名 + 大小；拖拽悬停时边框转墨色。
3. **预览**：统计条（总数 / 可导入 / 跳过 / 疑似重复 / 错误行，数字用等宽）+ 「包含疑似重复」开关 + 批量归类下拉 + 表格。
   - ≥md 用真表格（等宽数字右对齐）；<md 改卡片行。
   - 疑似重复行降透明度 + 「重复」徽标。
   - 未分类行的下拉框用琥珀描边提醒。
   - 导入中：顶部细进度条 + `已完成 120 / 380`。
4. **完成**：做成**收据样式**——纸纹背景 + 双线压边 + 逐行 `成功 N 条 / 跳过 N 条 / 失败 N 条` + 操作按钮。

### 4.7 AI 助手 `/ai`

- 占满视口高度的对话布局（`100dvh - 页头`），不随页面滚动。
- 用户消息右对齐墨色块；助手消息左对齐白底 + 发丝线（不是灰气泡）。
- 等待中：三点点动画（`rise` 一次）。
- 空态：一句引导 + 3 个建议问题 chip。
- 历史：点「历史」展开面板，最多 5 条可见 + 滚动；每条左为摘要首句（省略），右为删除。
- 输入区吸底，聚焦时边框转墨色。

### 4.8 管理面板 `/admin`

- ≥md：左侧 192px 子导航（sticky）+ 右侧内容；<md：横向滚动 chip。
- 7 个子页：概览 / 用户 / 邀请码 / AI / 质量 / 日志 / 规则。
- 指标格：去掉全部渐变，改为白底 + 顶部 2px 语义色条 + 等宽大数字。
- 用户：行内展开详情（统计三格 + 重置密码 + 删除）。
- 邀请码：邀请码用等宽 + 宽字距，可一键复制（复制成功改文案为「已复制」1.5s）。
- 质量：时间范围下拉 + 状态筛选 chip（成功/空/错误/超时用语义色）+ 日志行（原始输入单行省略，点击进详情）。
- 详情抽屉：每个阶段一段，`用户输入` / `清洗后` / `AI 返回` / `解析结果` / `最终提交` / `修正详情` / `错误`，分别用不同底色与等宽字体，JSON 超长可滚动。
- 日志：级别徽标（INFO 蓝 / WARN 琥珀 / ERROR 红）+ 模块名等宽 + 消息断行。
- 规则：JSON 编辑器（等宽、6 行、可拖拽高度）+ 版本列表（当前激活的版本墨色描边）。

### 4.9 我的 `/me`

- 用户块 + 分组 `Sheet`（财务管理 / 工具 / 系统），行 = 图标方块 + 名称 + 说明 + chevron。
- 「管理面板」仅管理员可见（`v-if`），非管理员不显示空分组。
- 底部「退出登录」描边红按钮，与其他行区分 24px 间距。

### 4.10 回收站 `/trash`

- 页头 + 「N 条待清理 · 30 天后自动清除」说明。
- 行：图标 + 描述 + 删除时间 + 金额 + 「恢复」（描边）「永久删除」（描边红）。
- 空态：纸纹 + 「回收站是空的」+ 「去记一笔」。

### 4.11 登录 / 注册 `/login` `/register`

桌面左右分栏（`1fr 420px`）：左为品牌面（纸纹底 + 账本双线 + 一句话说明），右为表单。手机单栏，表单位于品牌说明下方。

- 字段：label 在上（`0.6875rem/600/ink-3`），输入框 `.field`，聚焦时墨色边框 + 3px 扩散环。
- 错误：整块 `.notice-danger` 在表单顶部，不在字段下方重复。
- 主按钮：墨色，通栏，高度 44px。
- 注册：邀请码放第一位（它是门槛），并注明「需要邀请码才能注册」。
- 底部切换链接用墨色下划线，不用蓝色链接。

### 4.12 引导 `/onboarding`

4 步，顶部进度条（4 段横线），右上角「跳过」。

1. 欢迎：品牌符号（墨色方块内一个白色「¥」）+ 一句话 + 「开始设置」+ 三个能力短句（横排，非三张卡）。
2. 选账户：可多选；选中的行墨色边框 + 勾；行内可「设为默认」。
3. 设余额：仅对已选账户显示金额输入，`¥` 前缀内嵌。
4. 试记一笔：大输入框 + 示例短语两列网格 + 解析结果卡片 + 「确认记账」。成功后替换为完成态 + 「开始使用」。

## 5. 可访问性与质量底线

- 所有可交互元素有 `:focus-visible` 轮廓（2px 墨色 + 2px 偏移），键盘可达。
- 正文对比度 ≥ 4.5:1，`ink-3` 仅用于 ≥12px 的元信息。
- 触控目标 ≥ 36×36（行内小按钮 ≥ 28×28 且有 8px 间距）。
- 尊重 `prefers-reduced-motion`：全局动画时长归零。
- 禁止硬编码色值——一律走 CSS 变量，保证深色模式与主题唯一来源。
- 长文本（描述 >20 字、账户名 >12 字）在所有列表中单行省略，不得撑破布局。
